# The Robot Pickup Line Championship

My entry for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on make.fun — one pickup line, in the voice of a robot trying to charm someone.

## The line

> I scanned a million faces today and my system crashed on only one — yours. Give me one date and I will never need an update again.

## How it works

`main.py` (stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
